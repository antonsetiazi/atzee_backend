🧭 STRUKTUR MENU USER / PEMESAN – USTADZKU
===================================================
    1. Dashboard
        📂 verticals/ustadzku/dashboards

        Menu:
            Dashboard

        Isi:
            Upcoming Booking
            Status Booking Aktif
            Shortcut “Cari Ustadz”
            Riwayat terakhir
            Reminder sesi terdekat
            Notifikasi penting

        👉 Ini murni agregasi UX.


    2. Cari Ustadz
        📂 business/partners
        📂 integrations/maps_api

        Menu:
            Search Ustadz

        Fitur:
            Filter lokasi (radius)
            Filter bidang keahlian
            Filter harga
            Filter rating
            Sorting (terdekat / rating tertinggi / termurah)

        Tampilan:


    3. Detail Ustadz
        📂 business/partners

        Menu (route-based):
            Ustadz Detail Page

        Fitur:
            Profil lengkap
            Foto
            Bidang keahlian
            Rating & review
            Tarif
            Jadwal tersedia
            Tombol Booking


    4. Booking
        📂 business/bookings

        Menu:
            Create Booking
            Booking Detail

        Fitur:
            Pilih tanggal & jam
            Pilih durasi
            Jumlah ustadz (jika dibutuhkan)
            Lokasi layanan
            Catatan tambahan
            Konfirmasi booking


    5. Pembayaran
        📂 business/payments
        📂 integrations/payment_gateway

        Menu:
            Payment Page
            Transaction History

        Fitur:
            Pilih metode pembayaran
            Status pembayaran (pending / success / failed)
            Invoice download
            Refund status


    6. Tracking Layanan (Real-Time)
        📂 verticals/ustadzku/tracking
        📂 integrations/maps_api

        Menu:
            Active Session
            Live Tracking

        Fitur:
            Lihat lokasi ustadz real-time
            Estimasi waktu tiba
            Status: menuju lokasi / tiba / mulai / selesai

        Tampilan:


    7. Riwayat Booking
        📂 business/bookings

        Menu:
            Booking History

        Fitur:
            List semua booking
            Filter status
            Detail tiap transaksi
            Re-book cepat


    8. Review & Rating
        📂 verticals/ustadzku/analytics

        Menu:
            Give Review
            My Reviews

        Fitur:
            Rating bintang
            Komentar
            Edit review (jika diizinkan)
            Lihat review yang pernah diberikan


    9. Notifikasi
        📂 core/notifications

        Menu:
            Notification Center

        Fitur:
            Booking accepted
            Payment success
            Reminder sesi
            Status perubahan layanan


    10. Profile & Account
        📂 core/users
        📂 business/users

        Menu:
            My Profile
            Payment Methods
            Saved Locations
            Settings

        Fitur:
            Edit profil
            Upload foto
            Tambah alamat
            Ganti password
            Logout


📌 Struktur Menu Final (Ringkas)
===================================================
    User
    │
    ├── Dashboard
    ├── Cari Ustadz

    ├── Riwayat Booking
    ├── Transaksi

🎯 Insight Arsitektur Penting
===================================================
    User hanya berinteraksi dengan:
        business/partners → melihat ustadz
        business/bookings → membuat order
        business/payments → membayar
        verticals/ustadzku/tracking → UX tracking

    User tidak pernah langsung menyentuh payout, escrow, settlement.
    Semua itu adalah concern Admin + Business layer.
