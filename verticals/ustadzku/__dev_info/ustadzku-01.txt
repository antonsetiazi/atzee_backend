Kita sedang membangun APLIKASI USTADZKU.

1️⃣ Persona & alur utama
    User → mencari ustadz → booking → bayar → mengikuti tracking → layanan selesai → ustadz menerima payout.

    User: 
        bisa individu, lembaga, masjid

    Ustadz (mitra): 
        penyedia layanan, terdaftar di platform

    Platform (USTADZKU): 
        menampung order, menahan pembayaran sementara, forward ke ustadz setelah layanan selesai


2️⃣ Fitur untuk User / Pemesan

    A. Business layer
        Pencarian Ustadz
            Berdasarkan lokasi (radius), spesialisasi / bidang keahlian, rating, harga
        
        Booking / Order
            Pilih waktu, durasi layanan, jumlah ustadz (jika dibutuhkan lebih dari satu)
        
        Payment
            Bayar ke platform sebagai tanda booking
            History transaksi & status pembayaran


    B. Vertical layer (UX & Dashboard)
        Dashboard User
            Tracking lokasi ustadz secara real-time
            Notifikasi booking diterima, pembayaran berhasil, status layanan

        Review & Rating
            Setelah layanan selesai, user bisa memberi rating & feedback

        Reminder / Calendar integration
            Notifikasi sebelum sesi dimulai


3️⃣ Fitur untuk Ustadz (Mitra)

    A. Business layer
        Profil & Specialization
            Nama, kontak, foto, bidang keahlian
            Jadwal & availability
            Verified status & dokumen pendukung

        Tariff & service
            Tarif per sesi, paket, diskon promo

    B. Vertical layer
        Dashboard Ustadz
            Notifikasi booking baru
            Lihat jadwal hari ini / minggu
            Status pembayaran setelah layanan selesai

        Tracking & Location
            Update lokasi real-time agar user bisa track

        Chat / komunikasi opsional dengan user


4️⃣ Fitur untuk Platform Admin
    A. Business layer
        Manajemen Ustadz & Users
            Approve / reject ustadz, monitoring order & payment

        Reporting & Analytics
            Statistik order, revenue, rating ustadz, top performing ustadz

        Payout management
            Kelola dana yang ditahan → diteruskan ke ustadz setelah layanan selesai

    B. Vertical layer
        Dashboard Admin
            Overview semua order, tracking real-time, pembayaran pending / completed
            Notifikasi sistem untuk anomaly / keluhan


5️⃣ Integrasi (Integrations Layer)
    Payment Gateway
        Multi-metode pembayaran user → platform → forward ke ustadz setelah selesai

    Notifikasi / Messaging
        Email, WhatsApp, push notification

    Tracking & Maps API
        Real-time GPS tracking ustadz
        Google Maps / OpenStreetMap / Mapbox

    Calendar / Reminder integration
        Integrasi dengan Google Calendar atau internal reminder


💡 Alur singkat transaksi “USTADZKU”
========================================================================
    1. User buka aplikasi → cari ustadz (filter lokasi, bidang keahlian)
    2. Booking ustadz → bayar ke platform
    3. Ustadz menerima order → melakukan layanan
    4. User bisa track lokasi ustadz secara real-time
    5. Layanan selesai → pembayaran diteruskan ke ustadz
    6. User memberi rating / feedback
