1. CASHIER
    Fokus: Jual barang, terima pembayaran, cetak struk.

    Main Menu:
        - New Sale
        - Held Transactions
        - Return / Refund
        - Shift
        - My Transactions
        - Profile

    New Sale:
        Fitur:
            - Scan barcode
            - Search product
            - Add quantity
            - Discount (jika diizinkan)
            - Multi payment
            - Print receipt

    Shift:
        - Open shift
        - View shift summary
        - Close shift (jika diizinkan)

    Refund:
        - Search receipt
        - Partial refund
        - Full refund (mungkin butuh approval)

    Tidak boleh:
        - Lihat laporan global
        - Ubah konfigurasi
        - Akses outlet lain


2. SHIFT SUPERVISOR
    Fokus: Kontrol operasional harian dan approval

    Menu:
        - New Sale
        - Refund / Void Approval
        - Shift Management
        - Daily Sales
        - Cashier Activity
        - Transactions
        - Profile

    Shift Management:
        Fitur:
            - Open shift
            - Close shift
            - Cash in / Cash out
            - Over / short detection
            - Approve void

    Tidak boleh:
        - Ubah harga
        - Ubah pajak
        - Ubah payment method
        - Setup outlet


3. STORE MANAGER
    Fokus: Kontrol satu outlet penuh

    Menu:
        - POS
        - Shift
        - Reports
        - Inventory Snapshot
        - Staff
        - Payment Summary
        - Outlet Settings
        - Profile

    Reports:
        Report yang bisa diakses:
            - Daily Sales
            - Sales per Cashier
            - Sales per Product
            - Hourly Sales
            - Payment Method Breakdown
            - Refund Report

    Outlet Settings
        - Receipt template
        - Register setup
        - Default price list
        - Allowed payment methods

    Tidak boleh:
        - Ubah struktur accounting
        - Ubah global tax
        - Buat outlet baru


4. AREA MANAGER (Multi Outlet)
    Fokus: Monitoring banyak toko

    Menu:
        - Global Dashboard
        - Outlet Performance
        - Revenue Summary
        - Inventory Comparison
        - Staff Performance
        - Transaction Search

    Tidak bisa:
        - Melakukan transaksi
        - Buka shift


5. BACK OFFICE ADMIN
    Fokus: Konfigurasi sistem POS

    Menu:
        - Outlet Management
        - Register Management
        - Tax Profile
        - Payment Method Setup
        - Printer Setup
        - Receipt Template
        - All Reports
        - POS Permissions

    Ini biasanya hanya 1–2 orang.
