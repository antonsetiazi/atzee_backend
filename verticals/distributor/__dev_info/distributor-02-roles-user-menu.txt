🎭 STRUKTUR ROLE DI DISTRIBUTOR
=========================================
    Di dunia distribusi biasanya role seperti ini:

    | Level | Role                 | Fungsi                 |
    | ----- | -------------------- | ---------------------- |
    | L1    | Owner / Director     | Kontrol penuh          |
    | L2    | General Manager      | Operasional & strategi |
    | L3    | Sales Manager        | Tim sales & territory  |
    | L4    | Warehouse Manager    | Gudang & stok          |
    | L5    | Finance Manager      | Piutang & pembayaran   |
    | L6    | Salesman (Field Rep) | Jualan ke toko         |
    | L7    | Admin Sales          | Input SO & invoice     |
    | L8    | Warehouse Staff      | Picking & DO           |
    | L9    | Finance Staff        | Input pembayaran       |


    Kita kelompokkan menjadi 3 tipe besar agar lebih clean:
        👑 Executive
        🧠 Managerial
        🛠 Operational


🏠 MENU UNTUK EXECUTIVE (Owner / Director)

    Hanya monitor & approve.

🔐 VISIBILITY BERBASIS PERMISSION ENGINE
=========================================
    Frontend tidak tahu role.

    Backend kirim:

    {
        "menu": [
            {
                "label": "Sales",
                "permission": "sales.view",
                "children": [
                    {
                    "label": "Sales Order",
                    "permission": "sales_order.view"
                    }
                ]
            }
        ]
    }

    Core UI hanya render berdasarkan permission.
