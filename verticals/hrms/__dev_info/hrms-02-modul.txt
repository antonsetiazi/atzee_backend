Modul HRMS Yang Dibutuhkan
=========================================
    Kita bagi menjadi 6 pilar besar.


    1. Employee Management
        Entity:
            - Employee
            - Employment Contract
            - Employment Type
            - Department
            - Position
            - Branch / Location

        Fitur:
            - CRUD employee
            - Status: active, probation, resigned, terminated
            - Riwayat jabatan
            - Riwayat gaji
            - Dokumen (KTP, NPWP, dll)
            - Multi-branch

        Ini hanya entity + timeline.


    2. Attendance & Time Tracking
        Karena kamu sudah punya Shift Engine di core:

        Gunakan:
            - Shift
            - Shift Assignment
            - Check-in
            - Check-out

        Tambahan HRMS:

        Entity:
            - Attendance Record
            - Leave Request
            - Overtime Request

        Fitur:
            - Manual attendance
            - Approval leave
            - Approval overtime
            - Late calculation
            - Absence tracking

        Semua ini hanya workflow + entity.


    3. Payroll Engine (Vertical Logic + Accounting Engine)
        Payroll tidak boleh jadi bagian core.
        Gunakan Accounting Engine kamu.

        Entity:
            - Payroll Period
            - Payroll Slip
            - Payroll Component (Allowance, Deduction)
            - Tax Component

        Fitur:
            - Generate payroll otomatis dari:
                - Basic salary
                - Attendance
                - Overtime
                - Allowance
                - Deduction
            - Lock payroll period
            - Generate accounting journal otomatis

        Payroll = business rule + accounting entry.


    4. Leave Management
        Entity:
            - Leave Type (Annual, Sick, Unpaid, dll)
            - Leave Balance
            - Leave Request

        Workflow:
            Draft → Submit → Approve → Reject → Cancel

        Ini cocok sekali dengan workflow engine kamu.


    5. Performance Management (Optional tapi Future-Proof)
        Entity:
            - KPI Template
            - Employee KPI
            - Performance Review
            - Performance Score

        Fitur:
            - Penilaian periodik
            - Supervisor review
            - Scoring
            - Bonus reference

    6. Organization Structure
        Entity:
            - Company
            - Branch
            - Department
            - Position
            - Reporting Line

        Fitur:
            - Org chart
            - Supervisor mapping
            - Approval chain otomatis
