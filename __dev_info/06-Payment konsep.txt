## 🔄 FLOW UTAMA (WAJIB)

```text
Create Order
→ Create Payment (PENDING)

→ Call Payment Gateway
→ Return payment_url / token

→ User bayar (via gateway UI)

→ Webhook dari gateway
→ Backend proses:

    Payment = SUCCESS
    Order = PAID
    Booking = CONFIRMED
```

---

## ❗ RULE KRITIS

### 1. SOURCE OF TRUTH

```text
Payment success hanya dari backend (webhook)
Frontend tidak boleh menentukan status
```

---

### 2. RELATIONSHIP

```text
Order = financial intent
Booking = slot lock
Payment = transaksi uang
```

---

### 3. FLOW VALID

```text
Payment SUCCESS
→ Order PAID
→ Booking CONFIRMED
```

---

### 4. INVALID FLOW (DILARANG)

```text
Frontend set paid ❌
Payment langsung ke partner ❌
Order dianggap selesai saat bayar ❌
```
